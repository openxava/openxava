Actualización de librerías
--------------------------

* Include libraries not used in core? NO
    No usadas:
    - tomcat-dbcp	Cero referencias en Java/XML/properties. El datasource embebido usa HikariCP (OpenXavaAutoConfiguration). Parece resto de la época de context.xml + BasicDataSourceFactory.
    - hibernate-ant	SchemaTool usa org.hibernate.tool.schema.*, que está en hibernate-core, no en hibernate-ant. No hay tasks Ant ni org.hibernate.tool.ant.
    - commons-collections4	Ningún import org.apache.commons.collections4. El código usa commons-collections 3.x. El propio POM lo declara solo para forzar 4.5.0 por JasperReports/POI.
    - jackson-annotations	Ningún import Jackson en OX. Solo pin de versión (conflicto Spring Boot 4.1 / JR7).
    - groovy	Ningún uso en código OX. Solo comentarios en tests (“to be used from Groovy”). Es para apps de usuario / docs.
    No usadas pero útiles para aplicaciones:
    - jersey-client	openxavatest → BookService (ClientBuilder)
    - jersey-hk2	Runtime de Jersey client
    - jersey-media-json-binding	JSON-B con Jersey
    - jakarta.json.bind-api	BookService (@JsonbProperty)
    - hibernate-envers	Feature documentada (@Audited); OX solo silencia un logger de Envers
    - groovy	Entidades/scripts Groovy en proyectos de usuario
    Dejar:
    - commons-collections4
    - jackson-annotations
    - hibernate-envers (alineado con hibernate-core vía BOM de Spring Boot de OpenXava)
    Quitar:
