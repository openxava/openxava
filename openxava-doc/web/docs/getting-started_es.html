Sigue las instrucciones a continuación para crear y ejecutar tu primer proyecto OpenXava usando IntelliJ IDEA:

Crear un proyecto nuevo en IntelliJ

En primer lugar has de crear un proyecto nuevo usando un arquetipo Maven desde IntelliJ. Para ello escoge la opción File > New > Project...:

Una vez en el diálogo escoge la opción Maven Archetypes dentro de la sección Generators:

Después teclea el nombre del proyecto, invoicing en el campo Name:

Ahora es el momento de escoger el arquetipo. Para ello en el campo Catalog selecciona Maven Central y en el campo Archetype teclea openxava para que te muestre todos los arquetipos de OpenXava. Ahí escoge openxava-archetype.

Como versión escoge la última versión de OpenXava disponible, que actualmente es la 8.0.

Para finalizar, ve a la parte de abajo del diálogo y abre la sección Advanced Settings y en el campo GroupId pon com.yourcompany que es el valor que vamos a usar en este curso:

Si todo ha ido bien el diálogo debería haber quedado más o menos así:

Pulsa el botón Create para crear el proyecto.

Ahora tu proyecto ya está listo para empezar a escribir código:

Crear tu primera entidad

Desarrollar es muy fácil: solo has de añadir entidades para ir haciendo crecer tu aplicación. Las entidades se añaden en el paquete model. Abre la carpeta src/main/java, allí abre el paquete com.yourcompany.invoicing.model. Verás que contiene una entidad de muestra. Bórrala:

Ahora ya podemos añadir nuestras propias entidades. Empezaremos con una versión simplificada de Customer con solo number y name.

En la carpeta src/main/java selecciona el paquete com.yourcompany.invoicing.model y con el botón derecho del ratón escoge New > Java Class:

Después teclea Customer como nombre de clase y pulsa ENTER:

Fíjate que la C de Customer está en mayúscula, esto es muy importante, en Java todas las clases empiezan con mayúscula.

El código inicial que IntelliJ proporciona para Customer es muy simple:

package com.yourcompany.invoicing.model;

public class Customer {
}

Ahora, te toca a ti rellenar esta clase para convertirla en una entidad adecuada para OpenXava. Solo necesitas añadir la anotación @Entity y las propiedades number y name:

package com.yourcompany.invoicing.model;

import jakarta.persistence.*;
import org.openxava.annotations.*;
import lombok.*;
 
@Entity  // Esto marca la clase Customer como una entidad
@Getter @Setter // Esto hace los campos a continuación públicamente accesibles
public class Customer {
 
    @Id  // La propiedad number es la clave. Las claves son obligatorias (required) por defecto
    @Column(length=6)  // La longitud de columna se usa a nivel UI y a nivel DB
    int number;
 
    @Column(length=50) // La longitud de columna se usa a nivel UI y a nivel DB
    @Required  // Se mostrará un error de validación si la propiedad name se deja en blanco
    String name;
 
}

Con esto tienes el código suficiente (justo una clase) para ejecutar tu aplicación. Hagámoslo.

Ejecutar la aplicación

Abre el paquete com.yourcompany.invoicing y con el botón derecho sobre la clase InvoicingApplication escoge Run 'InvoicingApplication.main()':

Espera hasta que la consola muestre un mensaje diciendo "Started InvoicingApplication", como este:

Ya tienes tu aplicación ejecutándose. Para verla, abre tu navegador favorito (Chrome, Firefox, Edge o Safari) y ve a la siguiente URL:

    http://localhost:8080/invoicing

Estás viendo tu aplicación por primera vez. Para empezar pulsa en el botón Sign in:

Ahora, introduce admin/admin y pulsa en Sign in:

Después, en la parte de la izquierda se mostrará una lista de módulos, escoge Customers:

Usa el módulo Customers para crear nuevos clientes, simplemente introduce el número y el nombre y pulsa Save.

Pulsa en List para ver los clientes que has creado. Enhorabuena, tienes tu primera aplicación OpenXava funcionando.

Modificar la aplicación

A partir de ahora, desarrollar con OpenXava es muy fácil. Simplemente, escribes una clase y ya puedes ver el resultado en el navegador. Creemos una entidad para Product.

Selecciona el paquete com.yourcompany.invoicing.model y con el botón derecho del ratón escoge New > Java Class:

Después teclea Product como nombre de clase y pulsa ENTER:

Escribe el siguiente código para Product:

package com.yourcompany.invoicing.model;

import jakarta.persistence.*;
import org.openxava.annotations.*;
import lombok.*;
 
@Entity @Getter @Setter
public class Product {
 
    @Id @Column(length=9)
    int number;
 
    @Column(length=50) @Required
    String description;
 
}

Ahora, pulsa el botón Rerun, que es el botón verde que hay en la parte arriba del IDE. Esto parará la aplicación y la volverá a iniciar:

Para ver tu nueva entidad en acción abre tu navegador y ve a la URL:

    http://localhost:8080/invoicing/modules/Product

Después de identificarte con admin/admin obtendrás:

Sí, ya tienes un nuevo módulo en marcha, y solo has tenido que escribir una simple clase. Ahora puedes concentrarte en hacer crecer tu aplicación.
